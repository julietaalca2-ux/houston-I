# V0.23.0 4K Asset Catalog

All JPG maps in this folder are 4096x4096 procedural textures generated specifically for CIUDAD CERO.

4K base-color families: road asphalt; sidewalk concrete; red brick; stucco facade; roof tiles; urban grass; foliage; brushed steel; vehicle paint; tire rubber; vehicle glass; clothing fabric; skin microdetail; hair strands.

4K normal and roughness companions are included for the three primary world materials (asphalt, sidewalk concrete and facade stucco). Other existing 2K PBR companions remain active as mobile-friendly fallbacks. Desktop Ultra streams the 4K base-color set plus these primary 4K PBR maps.
