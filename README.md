# Ciudad Cero — Juego 01

Prototipo web 2D de mundo abierto con vista cenital, inspirado en la era de los juegos clásicos de conducción urbana. Universo, código y recursos originales.

## Ejecutar localmente
Abre `index.html` en un navegador moderno. No requiere instalación ni servidor.

## Controles
- WASD o flechas: moverse / conducir
- E: entrar o salir del auto (acércate al vehículo)
- Shift: correr / acelerar
- R: reiniciar

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, la carpeta `src/` y este README.
3. En Settings → Pages, elige Deploy from a branch.
4. Selecciona `main` y `/ (root)`, guarda.
5. GitHub te dará la URL pública del juego.
